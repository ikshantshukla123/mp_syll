# MP History · MPPSC Study Companion

A single-page, story-led study guide to the history, geography, polity, economy, culture and current affairs of Madhya Pradesh for the MPPSC State Service Examination.

## What is inside

- 15 narrative chapters mapped to the syllabus
- 34 sourcebook chapters in Part II
- 93 revision tables (site → district, dynasty → capital, event → year)
- 118-question prelims-style quiz with instant explanations
- Light and dark themes, reading progress bar and sticky chapter navigation
- Mobile-first layout: swipeable contents, stacked revision tables and large tap targets

## Files

| File | Purpose |
| --- | --- |
| `mp-history-mppsc.html` | The complete guide; a single self-contained page |
| `index.html` | Redirect so the repo root opens the guide on GitHub Pages |
| `mp.pdf`, `Know Your State Madhya Pradesh...pdf` | Source material used for the notes |

## Run locally

Open `mp-history-mppsc.html` in any browser, or serve the folder:

```sh
python3 -m http.server 8000
```

Then visit <http://localhost:8000>.

## Deploy on GitHub Pages

1. Push to the `main` branch.
2. In the repository, open **Settings → Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**, select `main` and `/ (root)`, then save.
4. The site opens at `https://<username>.github.io/mp_syll/`.

## Study tip

Read a chapter once for the story, then revise with the matching tables and the quiz. Do not memorise the page linearly: revise by matching site to district, dynasty to capital, event to year, and hero to movement.
